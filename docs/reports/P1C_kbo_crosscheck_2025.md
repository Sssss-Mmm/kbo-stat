## 1. KBO 공식 기록 접근

| 확인 항목 | 결과 |
| --- | --- |
| `https://www.koreabaseball.com/robots.txt` (요청 1회, 2026-10-24) | 첫 줄 주석: "본 사이트의 데이터를 사전 승인 없이 자동 수집·크롤링·복제하는 행위를 금지합니다." · `User-agent: *` → `Disallow: /` |
| 경기별 기록 요청 | **하지 않음.** robots.txt 가 모든 자동 수집기에 사이트 전체를 막고 명시적으로 금지해, 소량 검증 요청도 보내지 않았다 |
| 이용약관 | 사이트 열람은 하지 않았고(자동 요청 금지 대상), 웹 검색으로는 약관 본문을 찾지 못했다 — 사람이 직접 확인 필요 |

**결론: KBO 원본으로 직접 검증한 값이 없으므로 `kbo_verified` 는 0건이다.** 네이버 대조 상태(`naver_*`)는 그대로 보존했다.

### 기존 파이프라인에 대한 함의

`src/crawl_kbo_*.py`(순위·일정·타자/투수 기록·등록선수·관중·경기시간)는 매일 koreabaseball.com 을 자동 요청한다.
현재 robots.txt 기준으로 사전 승인 없는 자동 수집에 해당한다. 이번 작업에서는 바꾸지 않았다(승인 필요).

네이버: `m.sports.naver.com/robots.txt` 는 일반 수집기에 루트 외 전부 `Disallow`, 크롤러가 쓰는
`api-gw.sports.naver.com` 은 robots.txt 가 없다(404). 네이버 이용약관 확인도 필요하다.

### 대안

1. **KBO 사전 승인 요청** — 비상업 학습 프로젝트로 자동 수집 범위·빈도 승인을 받는다. 승인 범위 안에서만 `kbo_verified` 를 만든다.
2. **공식 데이터 라이선스** — 스포츠투아이 등 KBO 공식 기록 업체의 데이터 제공(유료 가능성).
3. **사람이 하는 표본 검증** — 우선 대상(콜드 7 · 무승부 22 · 끝내기 37 · 충돌 경기)을 사람이 KBO 게임센터에서 열람해
   확인자·시각·화면 근거를 남기고, 그 항목만 `kbo_verified`(출처 `kbo_manual`)로 표시한다. 자동 요청 없음.
4. 위가 되기 전까지는 네이버 박스스코어를 "공식 데이터의 2차 출처"로 명시해 쓰고, 화면에 `naver_verified` 로 표기한다.

## 2. 투수 교체 순간 아웃 귀속 (5경기 9건)

재현 결과(투구 순서·Out 변화):

| 유형(경기 수) | 상황 | 판단 |
| --- | --- | --- |
| 교체 직전 공이 타석을 끝내지 않음(1) | 앞 투수 마지막 공 = 사구, 다음 투수 첫 공 전에 Out +1 | 귀속 불명(도루자 vs 견제사) → 미확정 |
| 타석 도중 교체(1) | 교체 사이에 Out +1 | 귀속 불명 → 미확정 |
| 교체 직전 공이 안타(1) | 앞 투수 마지막 공 = 안타, 이후 Out +1 | 귀속 불명 → 미확정 |
| 원본 투수 표기 오류(1, 2개 반이닝) | 투구 데이터상 각 이닝을 한 투수가 다 던짐 — 원본 투수 표기 자체가 공식과 다름 | 투구 데이터로 고칠 근거 없음 → 충돌로 유지 |
| 순서 정상인데 불일치(1) | 희생플라이(앞 투수)→교체→뜬공(다음 투수) | 원인 불명 → 충돌로 유지 |

경기 단위 목록은 공개 문서에 두지 않는다(로컬 산출물 `kbo_outs_uncertain_2025.csv`, 사유 `pitcher_change_out`).

규칙(`build_player_games.pitch_outs`, 사유 `pitcher_change_out`): 교체 직전 공과 다음 공 사이에 Out 이 늘었는데
앞 투수 마지막 공이 **타석을 끝냈고 그 아웃을 보여 주는 문구**(타자 아웃·병살·삼중살·포스아웃 야수선택·낫아웃 뒤 아웃)가
아니면 그 반이닝을 믿지 않는다. 네이버 값에 맞추지 않았다 — 귀속이 분명한 곳은 그대로, 불분명한 곳만 미확정.

| 2025 전체 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 귀속 불명 반이닝 | — | 17 |
| 아웃 미확정 투수-경기 | 144 | 180 (+36) |
| 입증된 Outs: 일치 / 불일치 | 6,872 / 9 | 6,842 / 3 |
| 미확정 Outs: `naver_verified` / `naver_conflict` | 101 / 43 | 131 / 49 |

- 바뀐 값은 투수 36명-경기의 `Outs`(→빈 값)·`OutsComplete`(True→False)뿐이다. 다른 열은 그대로.
- 미확정으로 바뀐 36건 중 30건은 기존 값이 네이버와 맞았다(→ `naver_verified`), 6건은 틀렸다(→ `naver_conflict`).
