# P2-C 설계안 — 라이트팬 홈 · 시즌 순위표 · 날짜별 일정/결과

작성: 2026-10-24 · 구현 결과는 `docs/reports/P2C_frontend.md`.

> **정정(구현 중 확인)**: 아래 "2011 순위표 SK·롯데 원본 오류" 는 원본 오류로 단정할 수 없다. 2001–2022 중 12시즌에서 원본 순위가 정규시즌 승률 순서와 다르고 방향이 모두 그 해 포스트시즌 결과와 같아, 포스트시즌 반영 최종 순위일 가능성이 있다(포스트시즌 자료가 없어 미확정). 구현은 원본을 고치지 않고 `differs`(사유 미확정)로 표시한다.

## 0. 데이터 준비 상태 (실제 확인 결과)

| 데이터 | 있는 범위 | 저장 위치 | 출처 |
| --- | --- | --- | --- |
| 경기 일정·결과(홈/원정·점수·상태·구장·시간) | 2001–2026 정규시즌 | `data/raw/kbo_official/kbo_schedule_{시즌}.csv`, DB `schedule_games`(17,257행) | KBO 공식 사이트 자동 수집(2026-10-22 마지막, 이후 중단) |

검증 결과:

- **경기 상태**: 일정의 `status` 는 `final`/`scheduled` 둘뿐. 취소 경기는 `scheduled` + `Note`(사유) + `GameId` 없음으로 온다
  (2025: 완료 720 · 취소 84, 2026: 완료 720 · 취소 73). 무승부는 `final` 이고 두 점수가 같다. → 상태는 `final / tie / canceled(사유) / scheduled` 로 따로 만들어야 한다.
- **홈·원정·최종 점수**: 2025 720경기 전부 네이버 박스스코어(`scoreBoard.rheb`)와 팀·점수 일치(독립 출처 교차 확인).
- **승·패·무**: 일정의 완료 경기로 다시 센 값이 시즌 순위표와 **2001–2026 26시즌 전 팀 일치**.
- **승률 규칙**: 시대별로 다르다 — 2009·2010 은 승/경기(무승부=패 취급), 그 밖은 승/(승+패). 반올림은 **사사오입**(2011 롯데 .5625 → .563; 파이썬 기본 반올림은 .562).
- **승차**: ((1위 승 − 팀 승) + (팀 패 − 1위 패)) / 2 — 2024–2026 일치.
- **순위 결정**: 승률 동률이 7시즌(2011·2018–2022·2024). 공동 순위(2011 LG·한화 6위) 또는 상대전적·순위 결정전(2024 5위 KT·SSG)으로 갈렸다 → 계산만으로는 순위를 정할 수 없고 공식 순위표 값이 필요하다.
- **데이터 이상**: 2011 순위표 CSV 의 SK(2위)·롯데(3위) 순위가 승률·승차와 반대 — 수집 원본 오류로 보인다. 교차검증이 잡아야 하는 사례.
- **2025 / 2026 구분**: 두 시즌 모두 정규시즌 144경기 종료분까지 있다. 2026 포스트시즌은 없다. 날짜별 순위 이력은 2026 만 있다.

### 결정이 필요한 점 — 출처·이용 권한

일정·순위표·팀 경기 결과는 **모두 KBO 공식 사이트 자동 수집분**이다(2025 이전 포함). 2026-10-24 결정으로 수집은 멈췄지만
이미 저장된 자료를 화면에 어떻게 쓸지는 정해지지 않았다.

| 안 | 내용 |
| --- | --- |
| A | 저장된 자료를 모두 보여 주되 출처 "KBO 공식 사이트 자동 수집(이용 승인 확인 전) · 수집일" 을 표기 |
| B | 2026 은 숨기고 2025 이하만 표시(같은 출처라 권한 문제는 동일하게 남는다) |
| C | 이용 승인 전까지 KBO 수집분 화면 비공개(로컬 개발 화면에서만) |

설계는 시즌별 **표시 여부 플래그**로 세 안 모두를 지원한다. 어떤 안이든 2026 자료를 "현재 진행 중" 으로 보이지 않고
"수집 중단 시점(2026-10-22) 기준" 으로 표시하며, 2025 자료를 최신 시즌처럼 내세우지 않는다.

## 1. 화면 설계

기존 v1 홈·순위표·경기일정 화면을 그대로 두고 v2 데이터로 같은 자리를 보강한다(라우트 유지).

### 1.1 홈 (라이트팬 첫 화면)
- 상단 **데이터 기준 배너**: "자료 기준: 2026-10-22 수집분 · 이후 갱신 중단" — '오늘'·'현재 순위' 표현을 수집 중단 뒤에는 쓰지 않는다.
- 시즌 순위 요약(상위 5팀 + 전체 보기), **가장 최근 경기일**(오늘이 아니라 자료의 마지막 경기일)의 결과 카드, 각 카드 → 일정/박스스코어.
- 박스스코어 링크는 박스스코어가 있는 경기(2025)에만. 없으면 "상세 기록 없음".
- 기존 홈의 분석 카드(타이틀 레이스 등)는 아래로 유지.

### 1.2 시즌 순위표
- 시즌 선택(표시 허용 시즌만), 열: 순위 · 팀 · 경기 · 승 · 패 · 무 · 승률 · 승차 · 최근 10경기 · 연속 · 홈 · 원정.
- **검증 배지**: 시즌마다 "경기 결과로 계산한 승·패·무·승률·승차가 공식 순위표와 일치 / 불일치 n건".
- 동률 표시: 승률이 같은 팀은 "동률 — 공식 순위 기준(상대전적·결정전)" 주석. 계산 순위로 순위를 바꾸지 않는다.
- 시대 규칙 각주: 2009·2010 승률 산식 등.
- 날짜 기준 순위(through_date): 경기 결과로 그 날짜까지 계산한 순위(라벨 "경기 결과로 계산"). 2026 은 날짜별 공식 스냅샷과 비교 표시.

### 1.3 날짜별 일정·결과
- 날짜 선택 + 월 달력(기존 화면 재사용) + 하루 목록: 시간 · 원정 vs 홈 · 점수 · 상태(종료/무승부/취소(사유)/예정) · 구장 · 박스스코어 링크.
- 빈 날짜를 둘로 구분: "이 날 경기 없음"(시즌 범위 안) vs "자료 없음"(수집 범위 밖·포스트시즌·미수집 시즌).
- 더블헤더: GameId 13번째 자리(1·2차전) 표기.

## 2. API (추가만, v1 유지)

| 엔드포인트 | 응답 요지 |
| --- | --- |
| `GET /api/v2/seasons` | 시즌별 보유 범위(일정·순위표·박스스코어·날짜별 순위), 출처, 수집일, 표시 여부 |
| `GET /api/v2/schedule?date=` · `?season=&month=` | 경기 목록: 상태(파생)·취소 사유·더블헤더·박스스코어 유무·출처·수집일. 빈 날은 `reason: no_games / out_of_range` |
| `GET /api/v2/standings?season=&through_date=` | 계산 순위표 + 공식 순위표 대조(팀·항목별 일치), 동률 표시, 승률 산식, 출처 |
| `GET /api/v2/home?season=` | 기준 배너(마지막 수집·경기일), 순위 요약, 최근 경기일 결과, 리더 상위 링크 |

## 4. 순위 계산 검증 방법

1. 완료 경기로 팀별 경기·승·패·무를 세고, 시즌 승률 산식(시대별)과 사사오입으로 승률, 1위 기준 승차를 계산.
2. 공식 순위표와 팀·항목별로 대조 → `verify.standings_check`. 2001–2026 은 이미 승·패·무 100% 일치, 승률 산식 3종·반올림 규칙 확인.
3. 순위: 계산 승률 순서와 공식 순위가 다르면 사유를 분류 — 동률(공식 순위 사용) / 원본 이상(2011 처럼 승률·승차와 순위가 모순) → 이상은 화면에 그대로 표시하고 숨기지 않는다.
4. 점수 교차 확인: 박스스코어가 있는 시즌(2025)은 일정 점수와 박스스코어 점수 대조(현재 720/720 일치).
5. 회귀 테스트: 무승부·취소·더블헤더·2009 산식·사사오입·동률·2011 이상 사례 픽스처.

## 5. 우선순위

1. 출처·표시 정책 결정(0장) → `seasons` API·표시 플래그
2. 날짜별 일정·결과(+ 박스스코어 연결) — 데이터 준비 완료, 위험 낮음
3. 시즌 순위표 계산·대조 — 산식·동률·이상 처리 포함
4. 홈 — 1–3 위에 조립

## 6. 위험

- **이용 권한**: 일정·순위 자료 전부 KBO 자동 수집분 — 표시 정책 결정 전에는 공개 배포 불가.
- **최신성 오해**: 수집 중단 뒤 '오늘·현재' 표현이 남으면 2026-10-22 자료가 최신처럼 보인다 → 기준 배너·마지막 경기일 표기로 막는다.
- **순위 규칙**: 동률 처리·결정전은 계산으로 재현 불가 — 공식 순위표 의존, 공식 원본 오류(2011) 가능성.
- **포스트시즌 없음**, **박스스코어 2025 만** — 연결 가능한 경기가 시즌마다 다르다.
- **팀명 변경**: 과거 시즌 표기 통일 필요.
